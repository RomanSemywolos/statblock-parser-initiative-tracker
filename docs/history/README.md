# Historical development records

These files preserve experiments, audits, patch narratives, manual checklists, and validation output from earlier versions. They are intentionally not maintained as current documentation and may describe rejected designs or already-fixed defects.

- `patches/`: version-by-version change records
- `notes/`: superseded architecture, audits, research, and checklists
- `validation/`: captured output from old verification runs

For the current contract, use the repository `README.md` and the top-level documents in `docs/`.
