# Patch 2.74.27

- Tightened same-physical-line named-block proposals so ordinary prose such as `The dragon uses its Dread Visage.` is not promoted to a sibling feature candidate merely because several words are capitalized. Trusted physical-line feature starts are unchanged.
- Added bullet-aware Auto Style for internal subeffects: `• Antimagic Bomb.` / `• Force Breath.` now receive italic list-item styling instead of top-level bold-italic feature styling.
- The fix is surface/structure based and adds no D&D-specific feature vocabulary.
- Added regressions for the Imperial Dragon Multiattack shape and bulleted Breath Weapons options.
