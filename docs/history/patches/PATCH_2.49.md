# v2.49.0 — linked encounter cards and sidebar interaction

- Restores live statblock inheritance for encounter copies: the tracker and combatant-opened statblock read the current library working document/card configuration.
- Encounter-card pencil now edits per-combatant name, base HP, AC and six saving-throw modifiers without editing the source statblock.
- Saving-throw rolls on the right card show their latest total beside the clicked save.
- HP operation amount starts at 0 instead of 1.
- Wider desktop sidebars for long library names and encounter controls.
- The combat HP overlay above an opened encounter statblock displays the combatant's unique display name (#n or override).
